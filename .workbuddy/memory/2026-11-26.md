## 按钮绑定 GameFlow 流程函数的 void 包装

用户在 Button OnClick 下拉里找不到 `StartMatch` / `ReturnToMenu`，只看到 `InitializeGame`。

- **根因（Unity 硬规则，跨项目通用）**：`UnityEvent`（含 `Button.OnClick`）的 Inspector 绑定列表**只列出返回 void 的无参 public 方法**；返回 `bool` 的方法会被过滤。`GameFlow.StartMatch()` / `ReturnToMenu()` 返回 `bool`，故不显示；`InitializeGame()` 返回 void 所以能看到。
- **修复**：不动 bool 版 API（`GameUiController` 依赖其返回值做判断），在 `GameFlow.cs`（`ReturnToMenu` 之后）新增两个 void 包装专供 Inspector 拖绑：
  - `StartMatchFromUi()` → 调 `StartMatch()`，被拒时把 `MatchFlow.LastRejection` 打进 Console；
  - `ReturnToMenuFromUi()` → 调 `ReturnToMenu()`，同样输出拒绝原因。
- **绑定**：开始游戏 / 再来一局 → `StartMatchFromUi`；返回主菜单 → `ReturnToMenuFromUi`；`InitializeGame()` 返回 void 可绑，但开局/返回优先用包装。
- 文档：`Docs/10` 第七节补「按钮绑定注意」+ 附录清单；`Docs/00` 第八节同步。
- 编译：`.check/check.csproj --no-restore -p:GenerateDependencyFile=false -t:Rebuild` → 0 错误（2 条既有 MapKit CS0169 警告）。

### 补充：退出游戏入口（同日 20:53）
- 退出逻辑早已有：`GameUiController.HandleExitClicked()`（GameUiController.cs:591）—— `#if UNITY_EDITOR` 下 `EditorApplication.isPlaying = false`，打包版 `Application.Quit()`；但它是 **private**，OnClick 下拉选不到。
