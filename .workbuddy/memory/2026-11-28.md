## 精灵游侠：白底素材转序列帧 + 13 个剪辑 + 动作系统接入

### 素材前提（重要）
- 桌面「精灵游侠素材」原图是 **RGB 白底无 alpha**（其余三套角色都是透明背景），直接导入游戏里就是白框。文件名是 GBK↔UTF-8 乱码字面量，需先按 gbk→utf-8 还原再归集。
- 真正的高分辨率跑/跳/闪素材是 4 张 4128×1024 的 AI 参考条（JPG），GIF 只是 320×400 缩略图。
- 切条带时人物披风互相重叠、**没有纯白分隔列**，列投影找空白会失败；改用「预期等分位置 ±200px 内找墨量谷值」定切割点，再用 GIF 逐帧形状相似度匹配确认配对。

### 转换口径（`.tools/elf_ranger/build_frames.py`）
1. 软阈值抠底：`a = clamp((235 - min(R,G,B)) / 20)`，保留弓弦等浅色细节。
2. 去白污染：`C = (P - (1-a)·255) / a`，否则暗色地图上全是白边。
3. 近白淡绿光晕（治疗/光环）再乘色 `(0.52,0.86,0.60)`，不然是一坨白。
4. 边缘外扩 6 圈（bleed），避免双线性采样把透明区的白 RGB 混进边缘。
5. 统一画布 800×800、脚底 y=799、中心 x=400、人物高 583px。

- `Assets/Animations/ElfRanger/` 13 个剪辑：Idle 6@8 / Run 6@12 / Attack 10@20（撒放帧 6）/ Heavy 12@18（撒放帧 7）/ Heal 12@15 / Jump 6@12 / DodgeFwd·Back 6@15 / Halo 8@14 / BrambleGrow 8@16 / BrambleIdle 6@8 / BrambleFade 3@10 / Arrow 12@30。

- 接线：`CharacterInstance.BuildVisual` 加 Ranger 分支与移除项；`PlayerMotor` 移动/闪避(前后)/跳跃；`AbilityCaster` 平A 与破甲重箭改为「撒放帧才生成弹道」、Ego 播治疗+光环、Superego 生成荆棘；`ProjectileView.ApplyFrames` 让箭矢用序列帧（仅游侠启用）。

## 地图层：25×12 坐标统一 + 单图切镜落位

来源：用户提供 `地图.docx` 进度表，5.1 的「需要检查」项是「25×12 格坐标与角色坐标统一；当前是圆形擂台/6 锚点布局」。

### 根因（三条独立的错位）
1. 上一版只缩放 `BG_背景` / `Ground_地面25格` 两个子物体，**地图根节点没进设计坐标系**；MapKit 机制把特效放在 `localPosition=(格+0.5, 1)`、雷从 `y=12` 落下，于是全停在半空/25 列外。
2. `CameraFollow` 自由跟随，`MapScreenFitter` 只在 `OnEnable` 算一次 → 相机一动背景就跑出屏幕。
3. `MatchSpawner` 用 `arenaSpacing=14` 把三场摆成 x≈-14/0/+14，而屏幕只展示一张居中地图 → 玩家场次落在地图外。

### 做法
- 新增 `Assets/Scripts/Maps/MapStage.cs`：`MapStage`（背景世界矩形 + `GridSpace` 25×12 + 地面顶面 + 可玩圆）+ `MapStageBuilder`（唯一几何实现，把**根节点**缩放 `s` 并移到背景左下角）。
- `MapScene.Enter()` 自动 `Refit()`（不再依赖 Editor 菜单）；`BattleMapPresenter` 加 `MapShown` 事件与 `TryGetStage`。
- `MatchSpawner` 订阅 `MapShown` 重摆：玩家那场摆在中轴左右各 3 格、脚底贴地面上沿；其余两场停到地图右边界外（半径 0.5）。格宽同步给 `GameInput.Grid` / 三个 `unitsPerCell`。
- `CameraFollow.Clamp To Stage` 把相机限制在场地矩形内（16:9 下 Y 钉死、X 只能 ±1.53）。

### 数值（16:9，ortho 5）
`根缩放 0.833` / 背景 20.833×10 / 视口 17.778×10 / 格宽 0.8333 / 地面上沿 -4.167 / 可玩圆 圆心 (0,0.417) 半径 4.583 / 双方 x = ±2.5。

### 坑
- `parent.InverseTransformPoint(world)` 的结果是 **parent 局部坐标**，要赋给 `localPosition`（不是 `position`）。
- Editor 工具用 `Undo.RecordObject` 必须把**地图根节点**也记上，否则 Ctrl+Z 只还原了子物体。
- `MapScene` 新字段 `groundCollider` 是 `Collider2D`，Editor 里用 `SerializedObject` 赋 `BoxCollider2D` 可以，但 `SetRef` 的参数类型要写 `UnityEngine.Object`（否则 `Object` 与 `object` 歧义）。
- `.check` 两种配置（含/不含 `UNITY_EDITOR`）均 0 错误。
