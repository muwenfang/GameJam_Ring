# 角色数值 与 输入系统

## 一、角色数值

### 1. 资产在哪

| 资产 | 路径 |
|---|---|
| 单个角色 | `Assets/Data/Characters/Character_<代号>.asset`（Swordsman / SteamMechanic / Spartan / Ranger / Clockmaker / Strongman） |
| 总表 | `Assets/Data/Characters/CharacterRoster.asset`（按顺序引用上面六份） |

新增角色时：右键 Create → 钟声/角色基础数值，再拖进总表的 `characters` 列表。`PersonaId` 是主键，总表里同一个人设出现两次会被校验器报错。

### 2. 字段

`CharacterBaseStats`（ScriptableObject）：

| 字段 | 含义 | 来源 |
|---|---|---|
| `persona` | 人设 ID（0–5） | 文档 |
| `displayName` / `positioning` | 显示名、定位描述 | 文档 |
| `traitName` / `traitDescription` | 特质名与说明 | 文档 |
| `maxHealth` | 生命上限 | 文档 |
| `defense` | 防御值 | 文档 |
| `damageReduction` | 减伤百分比（0–1 的小数，如 0.14 = 14%） | 文档，可用公式回填 |
| `speed` | 速度（整数刻度） | 文档 |
| `moveSpeedCellsPerSecond` | 实际移速（格/秒） | 文档，= speed × 0.03 |
| `jumpHeightCells` | 跳跃高度（格） | 文档：六人都是 2 |
| `attackIntervalSeconds` | 平A 冷却 | 文档 |
| `basicAttack` | 平A 档案（见下） | 文档 |
| `dodgeDistanceCells` / `dodgeDurationSeconds` / `dodgeCooldownSeconds` / `dodgeGrantsInvulnerability` | 闪避参数 | **文档未给，占位值 3 / 0.25 / 3 / 是** |
| `designNotes` | 备注（记录文档歧义、占位值） | 本工程补充 |

`BasicAttackProfile`（平A）：`attackName`、`damage`（单发/单次伤害）、`windupSeconds`（前摇）、`rangeCells`（射程）、`widthCells`（宽度，近战用）、`projectileSpeed`（投射物速度，0 = 近战）、`projectileCount`（弹丸数）、`spreadDegrees`（散射角）、`returns`（是否回旋）。派生属性：`IsProjectile`（速度 > 0）、`IsFan`（弹丸数 > 1）、`GetPelletAngleDegrees(i)`。

### 3. 六人总表（与文档一致）

| 角色 | 生命 | 防御 | 减伤 | 速度 | 移速 | 平A 间隔 | 平A |
|---|---|---|---|---|---|---|---|
| 剑客 | 100 | 70 | 14% | 130 | 3.9 格/s | 0.7s | 横斩 4 伤害 / 前摇 0.15s / 2 格 / 宽 2 |
| 蒸汽机械师 | 110 | 82 | 16.4% | 108 | 3.24 格/s | 0.8s | 蒸汽铳 每枚 2 / 0.2s / 5 格 / 速 6 / 4 枚 / 28° |
| 斯巴达 | 116 | 120 | 24% | 72 | 2.16 格/s | 0.9s | 长矛 5 / 0.2s / 2 格 / 宽 1 |
| 精灵游侠 | 75 | 75 | **12.5%** ⚠️ | 110 | 3.3 格/s | 0.6s | 短弓 3 / 0.15s / 8 格 / 速 10 |
| 钟表师 | 96 | 96 | 19.2% | 108 | 3.24 格/s | 0.8s | 飞刃 4 / 0.2s / 5 格 / 速 8 / 回旋 |
| 力士 | 120 | 90 | 18% | 90 | 2.7 格/s | 0.9s | 出拳 3 / 0.2s / 1 格 / 宽 2 |

跳跃高度：六人统一 2 格。手动计算：剑客 70/500 = 0.14 ✓、机械师 82/500 = 0.164 ✓、斯巴达 120/500 = 0.24 ✓、钟表师 96/500 = 0.192 ✓、力士 90/500 = 0.18 ✓；游侠 75/500 应为 0.15，文档自己用 ⚠️ 标了 12.5%，**本工程保留文档值**。

### 4. 公式与文档特例

`CharacterBalance` 里集中两条公式（其他地方不许硬写 500 / 0.03）：

```csharp
ReductionFromDefense(defense)      // defense / 500
CellsPerSecondFromSpeed(speed)     // speed * 0.03
```

`CharacterBalance.HasDocumentedException(PersonaId.Ranger)` 返回 true —— 只有游侠是文档自己承认的例外。

### 5. 校验与一键回填（Editor 菜单）

- **钟声 / 校验 / 校验全部数据**：逐项跑 `CharacterBaseStats.CollectIssues`，与 `CharacterReferenceTable`（文档总表快照）比对；偏差按 Info 报，公式不符按 Warning，字段缺失按 Error。同时校总表人数是否 6、人设是否重复。
- **钟声 / 校验 / 按公式回填角色派生数值**：把所有人的 `damageReduction` / `moveSpeedCellsPerSecond` 改写成公式值（**游侠会被改坏**，所以有第二项）。
- **钟声 / 校验 / 按公式回填（含文档特例）**：回填时跳过游侠，保留 12.5%。

## 二、输入系统

### 1. 文件职责

| 文件 | 职责 | 依赖 |
|---|---|---|
| `InputKey.cs` | 键枚举（数字即存档格式，**只能追加不能重排**）+ 显示名 | 纯 C# |
| `InputKeyCatalog.cs` | 与 `KeyCode` 的互转、按键合法性校验 | UnityEngine |
| `InputActionId.cs` | 11 个动作 + 默认键 + 动作分类（移动/技能） | 纯 C# |
| `InputBinding.cs` | `InputBindingTable`：每个动作主键 + 备用键，改键冲突检测 | 纯 C# |
| `InputBindingSerializer.cs` | 映射表 ⇄ 文本，存取用 | 纯 C# |
| `InputSettings.cs` | ScriptableObject：默认键位、是否允许运行时改键、是否落盘 | UnityEngine |
| `GameInput.cs` | MonoBehaviour：每帧轮询 → `WasPressed` / `IsHeld` / `WasReleased` / `MoveAxis` | UnityEngine |

纯 C# 那半边（含存档序列化）在 `.check/belltest` 里被真实跑过断言，改序列化格式不会把存档写坏而无人察觉。

### 2. 默认键位（文档键位表）

| 动作 | 主键 | 备用键 |
|---|---|---|
| 向上 / 向下 / 向左 / 向右 | W / S / A / D | ↑ / ↓ / ← / → |
| 平A | 鼠标左键 | — |
| 闪避 | 鼠标右键 | — |
| 跳跃 | 空格 | — |
| 技能 1（本我） | 1 | — |
| 技能 2（自我） | 2 | — |
| 技能 3（超我） | 3 | — |
| 暂停 / 菜单 | Esc | — |

⚠️ 文档原文是「鼠标左键/：平A/闪避」——斜杠后面丢了一个键名（正文指向 §9-Q4）。本工程取 平A = 鼠标左键、闪避 = 鼠标右键，两边资产都写了备注，随时可在改键面板改掉。

### 3. 改键

**编辑器**：钟声 / 输入映射 / 改键面板 → 点某行的「主键/备用」，直接按想要的键（鼠标键也行），冲突会告诉你是谁占用了，Esc 取消 → 「保存到 InputSettings」写回资产。

**运行时**：`GameInput.Instance.TryRebind(action, slot, key, out InputActionId conflict)`；`allowRuntimeRebinding` 关掉时直接返回 false。成功会按 `persistToPlayerPrefs` 自动写 PlayerPrefs。

**存档格式**（`ring.input.bindings.v1`，纯文本，方便看一眼就懂）：

```
# ring.input.bindings v1
Attack=MouseLeft|None
MoveUp=W|UpArrow
```

存的是**枚举名字**不是数字：以后往枚举中间插一个键，老存档也不会整体错位。

### 4. 接入

1. 场景里放一个空物体 → 加 `GameInput` → 拖 `Assets/Data/Inputs/InputSettings.asset`。
2. 角色脚本里读：`GameInput.Instance.MoveAxis`、`.AttackPressed`、`.SkillPressed(SkillTier.Id)`。
3. 想换 Input System 包时，只需改 `GameInput.Poll()` 里的 `UnityEngine.Input.GetKey*` 三行，其余 API 不用动。

## 三、没做的部分

- 输入映射只有「键位」，没有手柄轴/死区/组合键。
- 角色数值只有数据与校验，没有挂到任何角色预制体上（本轮没有角色实体）。
- 技能与地图：按约定不动。
