# 钟声系统 — 结构与条款映射

## 一、一张图看数据流

```
        ┌─ 定时 30s（B4，仅普通阶段）
        ├─ 死亡（B3，必定位置钟声）
输入 ───┼─ 追踪（B5，必定位置钟声）
        └─ 手动/调试（B… 调试键 B）
                 │
                 ▼
        BellRuntime.RingRandomKind / Ring
                 │  1) SyncImmunityFlags（B13）
                 │  2) 选 IBellEffect
                 │  3) CanExecute → Execute
                 │  4) 落账：SequenceNumber++、Tracking.OnBellResolved（B7）、ResetTimer
                 │  5) UpdatePhaseFromCompleteSets（B9）
                 ▼
        BellResult { Kind, Trigger, Phase, Assignments, Swaps, Clone, Notes }
                 │  事件 BellRung / PhaseChanged
                 ▼
        战斗层 / 场地层 / UI 消费结果
```

`BellRuntime` 只管**规则与状态**：它不知道格子在哪、不知道血条长什么样。位置钟声的结果是「谁和谁换」的 `Swaps` 列表，真正把角色挪过去是场地层的事。

## 二、代码分层

| 文件 | 角色 | 说明 |
|---|---|---|
| `BellTypes.cs` | 枚举与文案 | `BellKind` / `BellTrigger` / `BellPhase` / `SkillTier` / `BellTrackingExclusion` |
| `BellCards.cs` | 卡牌 | `TraitCard(PersonaId)` = 身份即卡牌；`SkillCard(PersonaId, SkillTier)`；`HasCompleteSet` 判「集齐一套」 |
| `BellParticipant.cs` / `IBellParticipant.cs` | 参与者 | 只暴露 id、名字、在场/存活/豁免标记、手上卡牌 |
| `BellParticipantRegistry.cs` | 名册 | `GetInPlay()` / `GetRedistributable()`（B13 过滤） |
| `BellRules.cs` | 规则数值 | 30s、6 区域、3 场、追踪 2 次、复制体 0.8、回血 20%（全部有文档默认值） |
| `BellTrackingLedger.cs` | 追踪账本 | 建立、按钟声递减、B7 排除判定 |
| `BellComponentPool.cs` | 组件池 | B11 收卡、B11「选一个带走」 |
| `BellPairingUtility.cs` | 配对 | 打乱后两两配对，落单者单独返回（B8 3 场 1v1、B12 奇数） |
| `TraitBellEffect.cs` | 特质钟声 | 收齐 → 洗牌 → 按原持有量发回 |
| `SkillBellEffect.cs` | 技能钟声 | **按等级分别洗牌**，保证每级恒为 6 张 |
| `PositionBellEffect.cs` | 位置钟声 | 两两配对 → `Swaps`；奇数时淘汰制给 `Clone`、普通阶段记「轮空」 |
| `BellRuntime.cs` | 流程机 | 计时、判定、落账、阶段切换、击杀收益、胜利判定 |
| `BellSettings.cs` / `BellSystem.cs` | Unity 侧 | 资产包装 + MonoBehaviour 外壳（计时、调试键、事件转发） |

**核心不许 `using UnityEngine`**：`.check/belltest` 把核心源码编进控制台程序，谁破坏这条约定，离线测试立刻编译失败。

## 三、条款 B1–B14 与代码位置

| 条款 | 文档规则（摘要） | 落点 | 说明 |
|---|---|---|---|
| **B1** 三种钟声 | 特质：收齐→洗牌→重分；技能：同理但**每种等级各一个**；位置：场上剩余的人互换 | `TraitBellEffect.Execute`<br>`SkillBellEffect.Execute`<br>`PositionBellEffect.Execute` | 技能按 `SkillTier.Id/Ego/Superego` 三级**各自独立**洗牌，所以每级不会串味；发牌按「各自原持有量」守恒，牌不会凭空多出或消失 |
| **B2** 作用范围 | 三种钟声的目标都是场上剩下的所有角色 | 各 `Execute` 里统一取 `Registry.GetInPlay()` / `GetRedistributable()` | 不做 1v1 局部钟声；淘汰者（`IsInPlay=false`）不参与 |
| **B3** 触发源①死亡 | 出现死亡**一定**触发钟声，且**必定为位置钟声** | `BellRuntime.NotifyDeath` → `Ring(BellKind.Position, BellTrigger.Death)` | 普通阶段、淘汰制都会敲 |
| **B4** 触发源②定时 | 无人集齐人设时每隔 **30s** 触发一次，种类随机 | `BellRuntime.Update` + `ResetTimer` + `RingRandomKind(BellTrigger.Timer)` | 只在 `BellPhase.Normal` 推进计时；一进淘汰制就停表（文档写该条款仅普通阶段） |
| **B5** 触发源③追踪 | 击杀后选择追踪，**本次钟声必定触发位置交换** | `BellRuntime.NotifyTracking` → `Ring(BellKind.Position, BellTrigger.Tracking)` | 先记账再敲钟 |
| **B6** 击杀收益 | 二选一：**夺取**其 1 个特质或技能；或**追踪**某持有者 | `BellRuntime.TryStealOneCard(winner, victim)`<br>`BellRuntime.NotifyTracking(tracker, target)` | 夺取先抢特质再抢技能（文档未定顺序）；失败返回 false，调用方走 B11 的「回血 20%」 |
| **B7** 追踪持续 | 持续**两次钟声**；若下次钟声为人为触发，追踪双方**不能成为追踪对象** | `BellTrackingLedger.BeginTracking(tracker, target, Rules.TrackingDurationBells)`<br>`OnBellResolved()`<br>`IsExcludedFromTrackingSelection(...)` | 「不能成为追踪对象」有两种读法：默认 `BellTrackingExclusion.SelectionOnly`（只剥夺「新的追踪目标」资格），可切 `SelectionAndPosition`（连位置交换也跳过） |
| **B8** 死亡后（普通） | 被杀方重分配到 6 区域之一、**生命恢复至满**，钟声重新匹配对手，仍是 3 场 1v1 | `BellRuntime.NotifyDeath`（普通阶段只置 `IsAlive=false`，**不淘汰、不挪牌**）<br>`BellPairingUtility.PairInOrder / PairShuffled`<br>`BellRules.RegionCount` / `MatchCount` | 区域分配与回满血是场地/战斗层的事，本层只给出 `Note` 提示与配对结果 |
| **B9** 阶段切换 | **有人集齐**则进入淘汰制 | `BellRuntime.UpdatePhaseFromCompleteSets`（每次 `Ring` 后自动调用）→ `PhaseChanged` 事件 | 切换后定时钟声停止 |
| **B10** 淘汰制差异① | 追踪变为**一次性** | `BellRuntime.NotifyTracking` 里 `duration = Phase == Elimination ? 1 : Rules.TrackingDurationBells` | 本次钟声敲完即失效 |
| **B11** 淘汰制差异② | 被淘汰者的卡全部进**组件池**，胜者可**选一个带走**；不换牌则**回复 20% 生命** | `BellRuntime.StoreEliminatedCards` + `BellComponentPool.TryGrantOneTo`<br>`BellSystem.EliminationHealPercent`（= `BellRules.EliminationHealPercent`，默认 0.2） | 池子拿不到牌时 `TryGrantOneTo` 返回 false → 调用方按「放弃夺取」结算回血 |
| **B12** 淘汰制差异③ | 位置钟声 + 剩余人数**奇数** → 落单者与**自己的复制体**对决，生命与防御低 20%；偶数时复制体消失 | `PositionBellEffect.Execute` → `BellResult.Clone`（`BellCloneRequest`：源角色、生命倍率、防御倍率）<br>`BellPairingUtility.FindLeftoverId` | 复制体只在淘汰制出现；普通阶段奇数只记「本轮轮空」。真正生成复制体由战斗层按 `Clone` 请求做 |
| **B13** 集齐者豁免 | 集齐人设的角色**不会再被随机分配**技能与特质 | `BellParticipantRegistry.GetRedistributable()`（`!BellCards.HasCompleteSet(...)` 为硬判定）+ `BellRuntime.SyncImmunityFlags()` | 位置钟声**不豁免**（文档只写技能与特质）；夺取（B6）也不豁免，豁免只认「集齐一套」 |
| **B14** 胜利条件 | 集齐完整人设**并且**只剩最后一人 | `BellRuntime.CheckVictory()` | 只满足「集齐但场上还有人」不算赢 |

## 四、关键状态机

```
BellPhase.Normal ──── 有人集齐（B9）────► BellPhase.Elimination
   30s 自动钟声（B4）                     无定时钟声
   死亡 → 位置钟声，人留场（B8）           死亡 → 位置钟声，人离场 + 牌进池（B11）
   奇数人数 → 本轮轮空                     奇数人数 → 复制体（B12）
   追踪持续 2 次（B7）                     追踪只 1 次（B10）
```

## 五、扩展点

| 想改什么 | 改哪 |
|---|---|
| 钟声间隔、追踪次数、复制体倍率、回血比例 | `Assets/Data/Bells/BellSettings.asset`（Inspector 改，不用碰代码） |
| 换掉某一种钟声的实现 | `BellRuntime.RegisterEffect(new MyTraitBellEffect())` |
| 让随机可复现（回放/测试） | 构造时注入：`new BellRuntime(registry, rules, new BellRandom(seed))`（`Random` 属性只读） |
| 加一种触发源 | 调 `BellRuntime.Ring(kind, trigger)`，新 trigger 加进 `BellTrigger` |
| 换 B7 的读法 | `BellSettings.trackingExclusion` 切 `SelectionOnly` / `SelectionAndPosition` |

## 六、这层没做的事

| 项 | 现状 |
|---|---|
| 位置钟声的实际位移 | 只输出 `Swaps`（谁换谁），不移动 GameObject |
| 6 区域分配（B8） | 只给 `RegionCount` 与提示，没有具体区域数据与座位表 |
| 复制体实体（B12） | 只给 `Clone` 请求（源角色 + 生命/防御倍率），不实例化对象 |
| 血量结算（B8 回满、B11 回 20%） | 只把百分比暴露给上层，本层不写血 |
| 技能的实际效果 | 技能只有「人设 + 等级」的身份，没有伤害/冷却/位移逻辑 |
| 钟声演出 | 无音效、无镜头、无 UI；只有 `BellRung` 事件和可选日志 |
