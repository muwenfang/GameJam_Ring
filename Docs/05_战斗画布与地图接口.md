# 05 · 战斗画布与地图接口

本轮改动两件事：**开局后显示 `battleCanvas`**，以及**按本局随机到的地图展示场景**。六张地图的实体尚未制作，本次只把「随机 → 选图 → 展示」的调用链和挂接接口建好。

## 三、六个地图的接口约定

### 编号与槽位

`BattleMapId` 目前是中性占位名 `Map01`…`Map06`，值 **0..5 连续**。等六张地图定名后直接改枚举成员名即可，值不要动 —— `BattleMapPresenter.Scenes` 数组是按枚举值当下标一一对应的：

```
Scenes[0] → Map01    Scenes[1] → Map02    Scenes[2] → Map03
Scenes[3] → Map04    Scenes[4] → Map05    Scenes[5] → Map06
```

`BattleMaps` 提供 `Count` / `All` / `IndexOf` / `FromIndex` / `Pick(int)` / `Pick(Random)` / `ClampToValid` / `IsDefined` / `ToDisplayName`。随机源由调用方注入：Unity 侧传 `UnityEngine.Random.Range(0, 6)` 的结果，纯映射逻辑本身不碰 Unity API，因此可以离线测边界。

> 注意与 B8「六区域」区分：`BattleMapId` 是**这一局选哪张地图**；每张地图内部的 6 个区域锚点是 `MapScene.RegionAnchors`，属于另一个层次。

### 为什么地图不是 Image

`battleCanvas` 里现有一张全屏 `bg1` 背景图，但**地图不等于换这张图的 Sprite**。一张地图是一整棵可带脚本的 GameObject 层级：背景分层、地面与碰撞、出生点、灯光、粒子、动画，将来甚至可能是叠加加载的独立 Scene。所以接口设计为：

- 切换单位 = `MapScene`（挂在一张地图的**根节点**上），不是 `Sprite` / `Image`；
- `BattleMapPresenter.Show(id)` = 其余五张 `Exit()` + 选中的 `Enter()`，不碰任何贴图字段；
- `MapScene.Enter()` / `Exit()` 是 `virtual`，默认只做 `gameObject.SetActive(true/false)`。做地图实体时按需重写：初始化地形与碰撞、摆出生点、切相机边界、播放入场演出、`SceneManager.LoadSceneAsync(..., Additive)`、退出时卸载；
- `MapScene.RegionAnchors`（可选 6 个 `Transform`）预留给 B8 六区域与位置钟声 `BellResult.Swaps` 的空间落点，`GetRegionAnchor(i)` 未配置返回 null。

`MapScene` 刻意不是 `abstract`：六张地图还没做时，也能先挂一个空根物体占位、验证随机链路。

## 四、开局时序

```
点「开始游戏」
  → GameUiController.HandleStartClicked
  → GameFlow.StartMatch()
      ① CurrentMap = BattleMaps.Pick(Random.Range(0, 6))   ← 先定本局地图
      ② Flow.StartMatch() → StateChanged(MainMenu → Loading)
           → GameUiController.ApplyState(Loading)
               battleCanvas.SetActive(true)
               BattleMapPresenter.Show(CurrentMap)
      ③ MapChanged 事件 → HandleMapChanged → Show(CurrentMap)（幂等，直接返回）
  → 生成六人 → StateChanged(Loading → Collect) → ApplyState 再 Show（幂等）
  → 结算 / 返回主菜单 → ApplyState(MainMenu) → battleCanvas 隐藏 + Hide()
```

**先赋值 `CurrentMap`、再 `Flow.StartMatch()`** 是刻意的：`StateChanged` 在 `Flow.StartMatch()` 内部触发，UI 收到 `Loading` 时读到的必须已经是本局的地图，否则会闪一帧上一局的值。

`GameFlow` 上另有两个调试字段：`Randomize Map`（默认开）与 `Fixed Map`。关掉随机后固定用 `Fixed Map`，方便只测某张地图。

## 五、Inspector 接线清单（需要你做的）

1. **战斗画布**（二选一）
   - 把场景里现有的 `BattleGround` Canvas 改名为 `battleCanvas`；或
   - 保持原名也行 —— 代码按 `battleCanvas` 优先、`BattleGround` 兼容、大小写不敏感自动查找；最稳妥是直接把它拖进 `GameUiController` 的 **Battle Canvas** 槽位。
2. **挂展示器**：新建一个空物体（或挂在 `battleCanvas` 上），加 `BattleMapPresenter`。场景里没有时代码会自动找；找不到会打警告，但不阻断开局。
3. **六张地图实体（现在不做也可以）**：每张地图建一个根 GameObject → 挂 `MapScene` → 设置 `Map Id` → 建议根节点在场景里**存成隐藏**（`Show` 只会激活选中的那张，初始全激活会六张叠在一起）→ 依次拖进 `Scenes[0..5]`。
4. **可选开关**：`Keep Battle Canvas On Result`（结算是否保留战斗画布）、`Show Hud With Battle Canvas`（是否叠加运行时 HUD）。

`battleCanvas` 与 `BattleMapPresenter` 都是新增序列化字段，C# 侧给了默认值/自动查找兜底，**即使一个槽位都不拖，Play 也能正常开局**（自动找到 `BattleGround` 并显示），只是地图场景不会切换。

## 六、降级行为与日志

| 情况 | 行为 |
|---|---|
| 没挂 `BattleMapPresenter` | 每局仍随机地图，`[流程] 本局地图：地图 N` 照常打印；界面不切地图，启动时打一条警告 |
| 选中槽位为空（`Scenes[i] == null`） | 其余五张 `Exit()`，本局不显示地图，每局打一条明确警告指向槽位下标 |
| 收到非法编号 / Inspector 里手填了越界值 | `Pick` / `ClampToValid` 折回合法范围，不抛异常 |
| 找不到 `battleCanvas` | 启动时打警告，界面切换仍按主菜单 / HUD / 结算原逻辑工作 |

`BattleMapPresenter.Show()` 是**幂等**的：`Loading → Collect → Elimination` 每次状态切换都会调，但同一张地图不会反复触发 `Enter()`；回主菜单 `Hide()` 后下一局重新 `Show` 才会再次进入。

## 八、明确没做的

- 六张地图的实体（地形、美术、碰撞、出生点、演出）一律没做，只有 `MapScene` 这个挂接点和 6 个槽位。
- `RegionAnchors` 只是预留数组，位置钟声 `BellResult.Swaps` 仍无人消费。
- 地图不影响角色数值、钟声规则与胜负判定；`CurrentMap` 目前只有 UI 在读。
- 没有转场动画、没有按地图切 BGM / 相机，也没有把地图做成独立 Scene（想做时在 `MapScene.Enter()` 里叠加加载即可）。
