## 二、已修的三处缺陷

### 1. 技能没有动画（最像「没反应」的元凶）

`ExecuteAbility()` 里，非冲刺、非弹道的技能直接调 `ResolveShape(...)` 结算：
伤害在第 0 帧就生效，画面上角色保持跑步/站立帧，**没有任何挥砍或出拳**。
玩家只能看到血条变化，第一反应就是「技能没生效」。

修法：与平A完全一致的范式——先播施法者自己的攻击分镜，命中帧再结算。
朝向在**按下瞬间**锁定（结算可能晚 0.15s，届时鼠标可能已移开）：

```csharp
Vec2 aimedDirection = GetAimDirection();          // 按下瞬间锁定朝向
System.Action resolve = () => ResolveShape(definition, aimedDirection, ...);
if (TryPlayCasterAction(resolve)) return;          // 剑客 PlayAttack / 力士 PlayPunch
resolve();                                         // 没有动画资源时兜底立即结算
```

> **2026-11-28 平A 朝向收口（策划口径）**：点击只「通知释放攻击」，不参与左右朝向的决定。
> `BasicAttack()` 里改成 `Vec2 aimedDirection = GetFacingDirection();`（取 `body.FacingVector`，
> 地面锁定时压成 `±1`），既不调 `SetFacing`，也不会因为鼠标在另一侧而反向。
> 技能施放仍走 `GetAimDirection()`（按鼠标选点，并同步精灵翻转）。

### 2. 冲刺动画按「技能来源人设」选，混装时无动画

```csharp
// 修改前：definition.Persona == Swordsman 才播剑士突刺
if (definition.Persona == PersonaId.Swordsman && animation != null && animation.PlayDash(resolve))
```

拆卡混装是本作核心机制（剑客完全可以装着力士的本我），此时
`definition.Persona` 是**力士**，而角色身上只有 `SwordsmanSpriteAnimation`，
两边的 if 都不成立 → `resolve()` 直接跑，角色**瞬移 5 格但仍在跑步帧**。

修法：动画按**施法者**选（与平A一致），技能来源人设只决定数值与判定形状：

```csharp
if (TryPlayCasterDash(resolve)) return;   // 施法者身上有哪套序列帧就用哪套
```

### 3. 静默失败

`Cast()` 的 `definition == null` 分支原来是裸 `return false`。
槽位为空（例如钟声把卡换走、或该局没发到这张）时，按键完全无输出，
是最难排查的一类「技能没反应」。

修法：改为 `LogWarning("[技能] 本我 槽没有技能卡…")`，并顺带说明按几号键。

## 三、新增的两个排查开关 / 入口

### 1. `GameInput.logActionPresses`（Inspector 勾选）

勾上后，任何动作按下都会打印动作名与当前解析到的键：

```
[输入] 按下 技能 1（本我）（技能 1（本我）：数字键1）
```

这条日志的作用是**把输入层和技能层切开**：
有它、没 `[技能] 施放`，问题在技能层；连它都没有，问题在输入层（键没收到）。

### 2. `AbilityCaster` 的三个 UI 调用入口

如果希望「点击技能卡图标」也能施放，**不需要额外写 UI 代码**：
在 Inspector 给按钮的 `OnClick` 拖 `AbilityCaster`，选下面任一无参方法即可。

| 方法 | 对应槽位 |
| --- | --- |
| `CastIdSkill()` | 本我（1 号） |
| `CastEgoSkill()` | 自我（2 号） |
| `CastSuperegoSkill()` | 超我（3 号） |

按约定（UI 由用户手工在 Inspector 搭、不自动生成），这里只提供可被拖拽的公开方法，
不生成任何按钮或 Canvas 物体。

## 五、需要你在 Unity 里做的三步

1. **打开诊断**：选中场景里的输入物体，勾上 `GameInput > Log Action Presses`；
   确认 `AbilityCaster`（运行时生成，选中 `玩家_剑客` 可见）的 `Log Casts` 为勾选。
2. **按一次 1**，Console 应出现两行：
   ```
   [输入] 按下 技能 1（本我）（…：数字键1）
   [技能] 施放 突进斩（冷却 4s）
   ```
   - 两行都有 → 链路通，之前「没反应」是无动画造成的观感问题，本版已修（会看到突刺分镜）。
   - 只有第一行 → 技能层拒绝（会紧跟一条 `[技能] …` 原因，例如冷却中 / 姿态中无法施放 / 槽没有技能卡）。
   - 两行都没有 → 键没进 Unity，请确认焦点在 Game 视图、且用的是**主键盘数字键**（不是小键盘）。
3. **Ctrl+R 刷新**，让改动的 `.cs` 重新编译（本次未新增文件，无 `.meta` 变化）。

## 六、未覆盖 / 遗留

- 离线校验**无法**覆盖 MonoBehaviour 生命周期、序列帧实际播放、`OnClick` 连线与 Inspector 引用。
- 技能动画目前复用「挥砍/出拳」分镜：素材只有 Idle/Run/Attack/Dash 四套，
  施法类技能（增益、护盾、召唤）也会挥一刀。要精确表现需要补素材或新增专用帧序列。
- 场景里仍有一个独立的 `PlayerMotor` 测试物体（坐标约 1050, 608，`isPlayer: 0`），
  它带 `CharacterInstance` + `CombatBody` + `PlayerMotor`。本次已让 `PlayerMotor` 只处理 `IsPlayer` 为真的角色，
  也让 `AbilityCaster.Update()` 只把全局键盘输入交给玩家；该残留物现在不会再抢输入或重复打印动作日志，之后可在 Unity 里手工删除。
- M3「缚地荆棘」的 3×1 地形与射程校验、M6 AI 行为决策器仍未实现。
