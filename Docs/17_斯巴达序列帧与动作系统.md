## 二、素材规格（实测）

素材位于 `Assets/Resources/Spartan/`，全部为单图 Sprite、`textureType = 8`、`spriteMode = 1`、`PPU = 100`、pivot 居中、背景透明。

| 序列 | 帧数 | 画布 | 人物包围盒（中位） | 脚底偏移 |
|---|---|---|---|---|
| `Thrust_00~05` | 6 | 234×230 | 234×149 | **114 px** |
| `Sweep_00~06` | 7 | 217×215 | 217×154 | **106.5 px** |
| `Shield_00~05` | 6 | 213×247 | 213×171.5 | **121.5 px** |

脚底偏移的定义与剑士 / 力士一致：`alpha 包围盒底边 y − 画布高/2`（PPU 100）。
三套画布尺寸不同，若统一按 Sprite 中心摆放，切换动作时脚底最多跳 **15 px**（scale 0.78 下约 0.117 世界单位），肉眼可见。组件按套锚定后脚底恒在 transform 原点。

**素材缺口：没有 Run / Idle 专用帧。** 处理方式：

- Idle 取 `Shield_00`（半举盾）——正好对应特质描述的「半举盾姿态」；
- 移动时保持该姿态，不虚构跑步摆腿；
- 组件会自动识别 `Run_*.png` / `Idle_*.png`，日后补素材即自动生效，无需改代码。

## 三、五个剪辑

| 剪辑 | 帧序 | 帧率 | 时长 | 循环 | 命中帧 |
|---|---|---|---|---|---|
| `Spartan_Idle` | `Shield_00` 单帧 | 10 fps | 0.100 s | 是 | — |
| `Spartan_Thrust` | `Thrust_00~05` | 15 fps | 0.400 s | 否 | **第 3 帧 = 0.200 s** |
| `Spartan_Sweep` | `Sweep_00~06` | 12 fps | 0.583 s | 否 | **第 3 帧 = 0.250 s** |
| `Spartan_Shield` | `Shield_00~05` | 12 fps | 0.500 s | 否 | 抬满即末帧 |
| `Spartan_ShieldHold` | `Shield_05` 单帧 | 10 fps | 0.100 s | 是 | — |

两处命中帧不是随手取的：

- **突刺 3/15 = 0.200 s**，与规格「前摇 0.2s」精确相等，所以伤害正好在枪尖刺出那一刻落地；
- **横扫 3/12 = 0.250 s**，`Sweep_03~04` 是弧光张到最大的两帧，伤害落在弧光出现时而不是抬手时。

`ShieldHold` 运行时不用（组件直接停在举盾末帧），它是给「改用 Animator」路线准备的保持态剪辑。

与剑士 / 力士一致，这些剪辑是**可预览、可微调资产**，运行时仍走代码切帧。

## 四、四层技能逐项落地对照

| 层 | 规格 | 数值定义 | 表现 | 判定 / 特殊逻辑 |
|---|---|---|---|---|
| 特质 | 斯巴达韧性：半举盾姿态，基础防御 +8；每秒回复 0.5 生命 | `DefenseFlatBonus = 8`、`HealPerSecond = 0.5` | 待机/移动常驻 `Shield_00` 半举盾 | `AbilityRuntime` 在 `PersonaId.Spartan` 分支累加 `defenseFlat` / `regen`（既有，本轮未改） |
| 普攻 | 长矛突刺：前方 2 格长 × 1 格宽；前摇 0.2s；伤害 5 | `Rect`、`AreaLength 2`、`AreaWidth 1`、`Windup 0.2`、`Damage 5` | ✅ `PlayThrust`，6 帧，命中帧 0.2s | ✅ 改为**正前方 2×1 矩形**选目标（本轮新增） |
| 本我 | 战阵横扫：前方 2×2 蓄力横扫；伤害 10；命中移速 −20% / 1.5s；CD 4s | `Rect`、`Area 2×2`、`Damage 10`、`Slow 0.2/1.5`、`CD 4` | ✅ `PlaySweep`，7 帧，命中帧 0.25s（本轮新增接入） | `ResolveShape` 按 2×2 矩形多目标结算 + 减速 |
| 自我 | 绝对防御：全举盾 2s；正前方 180° 受伤 −90%；自身移速 −50%；禁止普攻与本我；可再次点击提前解除；CD 5s | `Self`、`DamageTaken 0.10`、`MoveSpeed 0.5`、`CanCancelEarly`、`CD 5` | ✅ `BeginShield(2s)`：抬盾 0.5s → 保持 1.5s → 倒序收盾 | 姿态 `ShieldWall`：`FrontalOnly` + `DisableBasicAttack` + `DisableIdSkill`；背面受击由 `CharacterInstance.IsFrontalOnlyBackHit` 放行（既有）。提前解除调 `EndShield()` 立即收盾 |
| 超我 | 狂战：投矛前方 5 格（8 格/s，宽 1），首个目标 8 伤害；随后单刀狂战 3s：防御 −30%、平A 改单刀（射程 1、单发 2、间隔 0.5s）；结束后 1.5s 重新装备硬直（移速 −30%、无法攻击）；CD 6s | `Line`、`Range 5`、`ProjectileSpeed 8`、`AreaWidth 1`、`Damage 8`、`Duration 3`、`Defense×0.7`、`AttackInterval 0.5`、`BasicAttackDamage 2`、`CD 6` | ✅ 投矛复用 `PlayThrust`（枪尖刺出即弹道生成）；单刀阶段保持半举盾 | 弹道 `StopOnFirst = true` → 首个目标即停；结束后自动进入 `BerserkRecovery`（移速 0.7、禁普攻与技能） |

**本轮为「单刀射程 1 格」补的一处数据**：`AbilityRuntime` 的 `AttackRangeOverride` 是 `Math.Max` 语义，**只能加长不能缩短**，无法把长矛 2 格压成 1 格。因此在 `CombatStanceSpec` 增加 `BasicAttackRangeOverride`，`BerserkSpec` 填 `1f`，`AbilityCaster.FindBasicAttackTarget` 读取该值构造 1×1 矩形。走姿态表而不是改核心派生，避免影响其它人设。

## 五、组件改动

新建 `Assets/Scripts/Characters/SpartanSpriteAnimation.cs`，删除 `SpartanAnimatorDriver.cs`（无 `.meta`、无场景/prefab 引用，是尚未被 Unity 导入的桩文件）。

| 项 | 旧驱动器 | 新组件 |
|---|---|---|
| 驱动方式 | `Animator.SetTrigger/SetBool` + `Resources.Load("Spartan/Spartan.controller")` | 代码切 `SpriteRenderer.sprite`，与剑士 / 力士同构 |
| 实际效果 | **controller 不存在 → 加载为 null → 全部调用无画面** | 直接读 `Resources/Spartan` 下 19 张 Sprite |
| 脚底锚定 | 无 | 每套独立偏移（114 / 106.5 / 121.5），`localPosition.y = offset / PPU × scale` |
| 命中回调 | `WaitForSeconds(0.12f)` 硬编码；**横扫无回调** | 命中帧回调 + 播完 / 被打断三处兜底，只触发一次 |
| 举盾 | `PlayShield(duration)` 播一次布尔，无收盾 | 抬盾 → 保持（可提前打断）→ **倒序收盾** |
| 状态查询 | 无 | `IsThrusting / IsSweeping / IsShielding / IsShieldRaised / IsActing / IsMoving` |
| 资产核对 | 无 | 5 个 `AnimationClip` 字段 + `ClipsBound` / `DescribeClipBindings()` / `[ContextMenu("校验 AnimationClip 绑定")]` |

**举盾时序对齐**：`BeginShield(holdSeconds)` 传入的是**姿态总时长**（2s）。抬盾本身占 `6 / 12 = 0.5s`，所以保持段为 `2 − 0.5 = 1.5s`。若不扣这一段，盾会比防护效果多举 0.5s。

**收盾为什么倒序**：素材只有「半举盾 → 全举盾」六帧，没有单独的收盾动作。倒序播放 `Shield_05 → Shield_00` 正好是放下盾，不必新增素材。

## 六、接线与调用链

```
GameInput（左键 / 1 / 2 / 3）
  └─ PlayerMotor（移动 → SetMoving）
  └─ AbilityCaster
       ├─ BasicAttack()            → PlayThrust(命中帧结算) → ResolveBasicAttack
       ├─ Cast(Id)  → ExecuteAbility → TryPlayCasterAction → PlaySweep(命中帧结算) → ResolveShape
       ├─ Cast(Ego) → ApplyStance(ShieldWall) → BeginShield(2s) → CollectEndShield
       │              再次点击 → CancelStance + EndShield
       └─ Cast(Superego) → SpawnProjectiles(弹道自身结算) + PlayThrust(投矛表现)
                          → 3s 后 CombatStanceRuntime 自动转 BerserkRecovery
```

装配点：`CharacterInstance.BuildVisual()` 的 `persona == Spartan` 分支 `AddComponent<SpartanSpriteAnimation>()`，玩家与 AI 斯巴达实例都会挂上。
层级：`CharacterInstance`(根，挂 `CombatBody`/`PlayerMotor`/`AbilityCaster`) → `JumpOffset` → `Visual`(挂 `SpartanSpriteAnimation`)。
组件只改 `Visual` 的 `localScale` / `localPosition` 与 `SpriteRenderer.sprite`，纵向跳跃偏移仍由 `CombatBody.LateUpdate` 驱动 `JumpOffset`，两者不打架。

## 七、若改用标准 Animator（留给用户手工操作）

工程里**没有** `Spartan.controller`，也没改任何场景 / prefab。若要把 5 个剪辑改成 Animator 状态机播放：

1. 把 `SpartanSpriteAnimation` 从 `Visual` 上移除（**不能与 Animator 并存**：两者都写 `SpriteRenderer.sprite`，会互相覆盖）。
2. 在 `Visual` 上加 `Animator`，新建 `Spartan.controller`，拖入 5 个剪辑。
3. 参数：`Moving`（Bool）、`Thrust`（Trigger）、`Sweep`（Trigger）、`Shield`（Trigger）、`Shielding`（Bool）。
4. 建 Transition：`Idle ↔ Run`（Moving）、`Any State → Thrust/Sweep/Shield`（Trigger）、`Shield → Idle`（Shielding = false，Has Exit Time 关闭）。
5. **必须先统一 19 张 png 的 pivot 到脚底**，否则脚底锚定失效，切动作会跳 15 px（0.117 世界单位）。
6. 命中帧改用 **Animation Event** 转发，在 `Spartan_Thrust` 0.200s / `Spartan_Sweep` 0.250s 各插一个事件。

以当前「运行时生成 + 需要精确命中帧 + 三套画布尺寸不同」的结构，继续代码切帧风险更低。

## 九、Play 验收清单

1. 开局选斯巴达，人物显示为**半举盾的水墨剪影**（不是粉红方块、不是空白）。
2. 走动时保持半举盾姿态，脚底不上下跳。
3. 左键平A：播 6 帧突刺，**枪尖刺出那一帧**才掉血（约 0.2s），不是按下瞬间。
4. 站在敌人**背后**按左键：挥空、不掉血（2×1 矩形不穿身）。
5. 按 1「战阵横扫」：播 7 帧横扫，弧光出现时（约 0.25s）2×2 范围内的敌人才掉血并**变慢**。
6. 按 2「绝对防御」：抬盾 → 举满 → 保持约 1.5s → 自动收盾；期间正前方受击伤害约为原来的 1/10，**背后受击正常**；期间左键与 1 键无效。
7. 举盾中**再按一次 2**：立即收盾，姿态提前解除。
8. 按 3「狂战」：先播突刺（投矛），矛飞出 5 格命中首个目标掉 8 血；随后 3s 内平A 变成**近身单刀**（射程明显变短、每下 2 血、间隔约 0.5s）；3s 后进入 1.5s 硬直，移速下降且打不出攻击。
9. 连续快速点左键：每次都在命中帧结算，不因动作被打断而丢伤害。
10. 在 Animation 窗口拖入 `Spartan_Sweep.anim`，可逐帧预览 7 张姿势。

## 十、遗留边界

- **无 Run / Idle 专用帧**：移动时保持半举盾姿态。组件已支持自动识别 `Run_*.png` / `Idle_*.png`，补素材即生效。
- **无收盾 / 死亡 / 受击帧**：收盾用倒序播放代替；死亡与受击仍是既有占位表现，未做专门分镜。
- **单刀狂战无专用帧**：3s 内仍显示半举盾（数值与射程已按规格生效）。要精确表现需补「单手持刀」序列。
- **投矛无飞行姿态帧**：复用突刺分镜，弹道本体由 `ProjectileView` 表现。
- **闪避无序列帧**：`RequestDodge` 只做位移与无敌，不换姿态（与力士一致）。
- **AI 侧未验证**：AI 斯巴达会挂同一组件，但 AI 是否走到 `BasicAttack` / `Cast` 未在 Play 中确认；逻辑上共用同一入口。
- **AnimationClip 字段在运行时无效**：角色由 `MatchSpawner` 运行时生成、没有 prefab，Inspector 里拖的引用退出 Play 后不保留。要让绑定持久化，需先把角色固化成 prefab。
- **平A 判定口径变化会影响剑客 / 力士**：本轮把 `Rect`/`Fan` 形状的平A 统一改成按朝向选目标（技能表本来就是这么写的）。若实机手感偏严，可在 `AbilityCaster.FindBasicAttackTarget` 里对非斯巴达退回旧的最近单体口径。
